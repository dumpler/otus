# Краткое описание проекта

## Тема

Информационная система управления гибридным офисом: бронирование рабочих мест, учет сотрудников, хранение планов этажей и аналитика загрузки офисных пространств

## Цель

Показать проектирование и реализацию базы данных для реального бизнес-сценария, где часть данных приходит из внешней системы, а операционные данные ведутся локально

## Бизнес-сценарий

Компания использует гибридный формат работы

Сотрудники заранее бронируют рабочие места в офисе

Администраторы управляют офисами, этажами, зонами, рабочими местами, SVG-планами этажей и временной недоступностью рабочих мест

Справочники сотрудников, отделов и ролей ведутся во внешней системе, похожей на AD/LDAP

Основная БД получает эти данные через логическую репликацию PostgreSQL

## Архитектура

Проект использует два экземпляра PostgreSQL:

- `directory_db` - имитация внешнего каталога сотрудников, отделов и ролей
- `office_booking_db` - основная база данных системы бронирования

Внешний каталог публикует таблицы:

- `office.departments`
- `office.roles`
- `office.employees`
- `office.employee_roles`

Основная база подписывается на эти публикации и использует реплицированные данные в локальных бизнес-процессах бронирования

## Что демонстрирует проект

- нормализованную реляционную модель
- связи один-ко-многим и многие-ко-многим
- логическую репликацию связанных таблиц
- ограничения целостности
- запрет пересекающихся бронирований
- хранение SVG-планов этажей
- координаты рабочих мест на плане
- триггеры для бизнес-валидации
- историю изменения статусов
- аудит изменений
- аналитические SQL-отчеты
