# OTUS: Базы данных

Учебный репозиторий с домашними работами и выпускным проектом по курсу OTUS «Базы данных»

Основная сквозная тема работ - база данных `office_booking` для системы бронирования рабочих мест в офисе. На ее примере прорабатываются проектирование схемы, ограничения целостности, DDL и DML, индексы, транзакции, оконные функции, хранимые процедуры, триггеры, планы выполнения, репликация, восстановление из резервной копии и работа с разными СУБД

## Структура

## Выпускной проект

[Система бронирования рабочих мест в офисе](graduation_project) - итоговый проект курса

Он объединяет основные темы домашних работ: проектирование реляционной модели, ограничения, индексы, транзакции, триггеры, аудит, отчетность, материализованные представления и логическую репликацию связанных справочников из внешней базы

## Как работать с репозиторием

Каждая домашняя работа находится в отдельном каталоге `homeworks/<номер>` и содержит собственный `README.md` с целью задания, составом файлов, командами запуска и SQL-скриптами

Для большинства заданий используется Docker Compose:

```bash
cd homeworks/<номер>
docker compose up -d
```

Точные команды запуска и проверки указаны внутри README конкретной работы
